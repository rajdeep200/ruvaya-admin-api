# Manual QA

Run `npm run verify`, migrate a disposable PostgreSQL database, seed an admin, then cover: valid/invalid/rate-limited login; logout/session expiry/reset/revocation; unauthenticated and insufficient-role access; product create/edit/publish/archive, duplicate slug/SKU, price rules, variants, stock and media; CMS draft/preview/publish/revalidation failure; cart price/availability/coupon/idempotency races; all Cashfree sandbox statuses, retries, refresh, duplicate/invalid/delayed webhook and reconciliation; full/partial/excess/duplicate refunds; valid/invalid order transitions; analytics validation/dedup/PII rejection/ranges; malicious content, IDOR, CORS, oversized/unsupported media, CSV injection and secret leakage; desktop/tablet/mobile loading, empty, error, retry and unsaved-change behavior.
